Cartaz de dance

Tipo de madeira condensado, tinta preta em papel de cor, linhas de tamanhos diferentes, estrelas. Dá as letras e a paleta.

Dub plate

O selo branco, o carimbo, a data à mão. Disco único, feito para um sound system. É a tela de boot.

Caixa de som

A pilha do sound system, pintada à mão. Cada track é uma caixa; o cone empurra no golpe. É a HOME.

Ouça a ideia

rascunho em web audio · sintetizado · nada gravado

Um riddim de dois compassos em lá menor, 76 BPM, para sentir o desenho. Mute entra no próximo compasso (pisca enquanto espera). Segure THROW para mandar o skank e o cross-stick para o eco. VERSION mixa o dub sozinho.

Regras

o que vale para firmware, hub, editor e manual

Fazer

  • Papel e tinta: cores chapadas, textura de impressão com moderação (registro torto, tinta falhada).
  • Cor é track: vermelho bateria, verde baixo, ouro skank, azul bubble.
  • O som manda no desenho: o cone pulsa, o eco deixa rastro azul, o mute leva fita.
  • Letras grandes e condensadas; números em mono.
  • Status por palavra: QUIET, WARMING, ROCKING, HEAVY.

Evitar

  • Leão, retratos, folha, bandeira em faixas.
  • Símbolos religiosos do rastafarianismo; nyabinghi só com decisão do autor.
  • Patois de caricatura, nomes de artistas, estúdios ou riddims famosos.
  • Samples de disco; linhas transcritas de gravações.
  • Neon, brilho, gradiente.
